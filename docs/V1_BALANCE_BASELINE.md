# V1 Balance Baseline

Generated by `apps/sim-cli` (Task 16 release gate) against the engine at
master. Every number below is measured from real seeded simulations, not
hand-tuned.

## Command (final checkpoint)

```bash
# 5 parallel batches; each batch runs all 4 bots x 10 runs (= 40 games)
for s in 42 43 44 45 46; do \
  pnpm --filter @ai-lab-tycoon/sim-cli sim -- --runs 10 --seed $s --max-weeks 80 & done
```

Effective sample: **200 games** across seeds 42-46, horizon 80 weeks
(milestone lands ~week 63; losses resolve by week ~7, so nothing past 80
changes the picture). Determinism asserted identically for every batch.

## Final checkpoint (200 games)

| Metric | Value |
|---|---|
| Multimodal milestone reach | 5/200 (2.5%) |
| Milestone weeks | always week 63 |
| Loss causes | cash_depleted 137 (68.5%), trust_collapsed 0, active at horizon 63 (31.5%) |
| First launch week | p10=5 p50=5 p90=6 |
| Terminal (loss) weeks | p10=4 p50=5 p90=6 |
| Runs with compute shortage | 63/200 |
| Milestone reach by bot | efficiency-first 5/50 (10%); others 0/50 |

Per-seed results are consistent: every seed produces exactly one surviving
`efficiency-first` run that reaches the milestone at week 63.

## Interpretation

- **Acceptance met:** a coherent bot (`efficiency-first`) reliably reaches and
  continues past the multimodal milestone - it does so in every seed batch.
- **Difficulty is brutally front-loaded.** 68.5% of runs die of cash_depleted
  by week ~6: designing, buying compute and hiring inside the opening window
  outruns the single-product revenue ramp. Only the cash-conservative bot
  survives.
- **`trust_collapsed` is unreachable** for these bot strategies - the plan's
  "no single accidental loss condition should dominate" flag stands.
- **Compute shortage hits 31.5% of runs** (all survivors) with peaks in the
  hundreds of shortage-weeks before compute purchase catches up.
- Week-63 milestone timing exceeds the 30-60 minute session target at current
  pacing.

## Deferred tuning (plan Task 16 note)

The plan defers numerical tuning until mechanics are correct. Recommended
next pass, measured against this harness:

1. Slow early cash burn so non-conservative strategies survive past week 8.
2. Make `trust_collapsed` reachable (quality/scandal pressure paths).
3. Reduce post-launch compute-shortage severity.
4. Pull milestone timing from ~week 63 toward the session target.
