# AI Art & Asset Generation Plan

> **Owner:** Malcom (main agent) using built-in image-generation tools — no coding subagent.
> **When:** After Task 9 (game shell) exists, before/alongside Tasks 11–15. Art drops into real slots, not speculative ones.

## Goal

Generate a cohesive, dark "operations dashboard" art set with the image tools so the game looks polished rather than template-gray, then integrate via CSS/animations in a polish pass.

## Art direction (locked)

- **Mood:** late-night frontier AI lab — dark navy/near-black base, cyan + amber accents (matches existing shadcn dark tokens)
- **Style:** **illustrative characters** in a modern flat-with-depth game-art style — stylized human characters with strong silhouettes, rim lighting, and personality (think polished indie-strategy character art, not corporate clip-art). Environments/props stay semi-flat vector-tech; people are illustrated
- **Character cast:** the 3 advisors (research lead "Maya", ops/finance lead, growth lead) get full character portraits; rivals get distinct founder avatars; the founder gets a choose-your-archetype portrait set
- **Rule:** every asset generated from the same style-prefix prompt so the set reads as one game

**Shared style prefix (used in every prompt):**
> "stylized game character illustration, modern flat shading with soft rim light, deep navy background (#0a0e1a), cyan and amber accent glow, confident silhouettes, subtle sci-fi lab wardrobe details, painterly but clean, no text, no watermark"

**Shared environment prefix (non-character assets):**
> "dark tech operations-dashboard UI illustration, deep navy background (#0a0e1a), cyan and amber accent glow, clean semi-flat vector style, subtle grid texture, no text, no watermark"

## Integration & polish pass (Task 18)

- CSS only: fade/slide-in for report cards, pulse on blocking decisions, progress shimmer on training bars, count-up feel via transitions, reduced-motion respected
- Backgrounds/textures layered under existing shadcn components — **no component rewrites**
- Accessibility unchanged: icons never carry meaning alone; animations gated behind `prefers-reduced-motion`
